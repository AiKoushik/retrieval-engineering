# Code of conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
code of conduct. Everyone who takes part in its issues, pull requests
and discussions is expected to follow it.

## Reporting

To report unacceptable behavior, open an issue or contact the
maintainer, Ahsan Iqbal, via GitHub (<https://github.com/AiKoushik>).
If the report concerns something you would rather not discuss in
public, ask in a short issue for a private channel, without details.
Reports are handled promptly and with discretion, as the Covenant
describes.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
